# Autopilot Index execution plan

Authorized scope: execute the Atoms experiment, launch and observe the product, refresh ten company profiles, prepare a weekly intelligence digest, and measure the site funnel. Started 2026-09-10.

| MET-2 | Coordinator | Establish baseline and dashboard | Real provider counts with time window; unknowns clearly identified | MET-1 and provider access |
| REL-1 | Coordinator | Review, test and release integrated changes | Tests, production build, CI and route verification | Completed implementation tasks |

## Operating rules

- The three agents run concurrently on separate files; the coordinator owns shared integration and browser operations.
- Purchases, external messages and newsletter sending are not performed without specific authorization.
- Generated code is not evidence of a working product. Product creation is not evidence of demand, paid conversion or sustained autonomy.
- The experiment ledger records observed events. Unmeasured time, spending, usage and revenue remain null.
- Seven-day observation begins at the verified product launch, not the preparation date. No final demand conclusion is possible before that window ends.
- Profile review dates do not imply an announcement or pricing-change date. Existing historical claims remain clearly identified.

## Initial findings

- The repository already has 28 company profiles, evidence-first ranking, an Atoms protocol, and six published Pulse editions.
- The Andoni Chrome profile is connected. Atoms displayed its login page during preflight; the operator was asked to sign in. No build was submitted at that point.
- No existing analytics SDK or durable event store was found in the initial repository audit.
- Edition 6 was already published on 2026-09-10. The new digest is a separate reviewable draft; it must not overwrite or resend that edition.

Progress and final verification will be recorded in the execution report for this date.
